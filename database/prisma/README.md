# Prisma Schema Reference

This directory contains the Prisma schema representation for the **Google Business Profile** MySQL database (`googlebusinessprofile`).

## Usage with Prisma

If you wish to use Prisma CLI tools (such as Prisma Studio for database GUI browsing):

```bash
# Install Prisma CLI
npm install -g prisma

# Launch Prisma Studio GUI
prisma studio --schema=database/prisma/schema.prisma
```

The database URL will be read from your `.env` file (`DATABASE_URL`).
