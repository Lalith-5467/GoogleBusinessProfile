# Design System: Color Palette & Typography

The application employs a refined, professional modern design language centered around calming sage, olive, and celadon tones with clean neutral carbon typography.

## Color Tokens

| Token | Hex Value | Role | Usage |
| :--- | :--- | :--- | :--- |
| `carbon` | `#1D1E18` | Primary Text & High Contrast | Headings, primary labels, strong text |
| `olive.DEFAULT` | `#6B8F71` | Primary Brand Accent | Action buttons, active navigation, logo badge |
| `olive.hover` | `#597A5F` | Interactive Hover | Primary button hover state |
| `olive.active` | `#4E6B52` | Interactive Active | Button pressed state |
| `celadon.DEFAULT` | `#AAD2BA` | Secondary Accent | Highlights, table accents, selections |
| `celadon.light` | `#EAF4EE` | Soft Badge Background | Status indicators, pulse badges |
| `soft-bg` | `#F6F8F5` | Main Application Canvas | Page background |
| `surface` | `#FFFFFF` | Card & Panel Surface | Content containers, modals, table backgrounds |
| `border-ui` | `#DDE5DE` | Structural Borders | Cards, input borders, dividers |
| `muted-ui` | `#68736B` | Secondary Typography | Subtitles, helper text, table column labels |
| `success-ui` | `#2F7D4A` | Success Indicator | Active connection, completed scrapes |
| `warning-ui` | `#B7791F` | Warning Indicator | Warnings, partial data notices |
| `error-ui` | `#C94A4A` | Error Indicator | Failed requests, validation errors |

## Typography

- **Body Font**: `Inter`, system-ui, -apple-system, sans-serif
- **Heading Font**: `Manrope`, system-ui, -apple-system, sans-serif

## Border Radius Tokens

- `btn`: `10px`
- `card`: `16px`
- `modal`: `20px`
- `pill`: `9999px`
